# Data

This folder is empty on purpose, because the data is not mine to share.

- `airline_reviews/` holds one CSV per airline. Create the folder before running `1-review-insights/scraper.ipynb`, which writes into it. The scraper also writes `review_scores.csv`, `review_comments.csv` and `review_ratings_df.csv` here.
- `customer_booking.csv` is the booking data from the programme, used by `2-booking-prediction/booking-model.ipynb`. The notebook downloads it, or you can enrol in the simulation on Forage and download it there.
